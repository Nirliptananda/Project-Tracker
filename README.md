# Project Tracker

A responsive Kanban board for tracking projects through Backlog, In Progress, Review, and Completed.

## Repository

[View the source on GitHub](https://github.com/Nirliptananda/Project-Tracker)

## Features

- Core: semantic four-column board, category labels, empty states, and responsive layout.
- Tier 1: add projects with validation, delete projects, and live column counts.
- Tier 2: move and edit projects, and search by project name.
- Tier 3: save board data in localStorage, show status totals, and drag projects between columns.
- Tier 4: dark mode and updates shared across open tabs.

## Tech stack

- HTML5 and CSS3
- JavaScript with React 18 loaded from a CDN
- Babel Standalone compiles JSX in the browser
- No npm, build step, backend, or additional libraries

## Run locally

The static core works with JavaScript disabled. To run the React features, open the project with the VS Code Live Server extension so the browser can load `app.js` and compile its JSX.
